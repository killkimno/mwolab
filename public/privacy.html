MwoLab 개인정보처리방침

시행일: 2026년 8월 26일 · Last updated: August 26, 2026

MwoLab로 돌아가기

1. 적용 범위와 운영자

이 방침은 MwoLab 웹사이트와 공개 핏팅 기능에 적용됩니다. MwoLab은 별도의 자체 서버나 자체 비밀번호 계정 시스템을 운영하지 않습니다. 개인정보 관련 문의와 삭제 요청은 killkimno@gmail.com으로 보낼 수 있습니다.

2. 처리하는 정보

  • Google 로그인: Firebase Authentication을 통해 Google 계정의 고유 사용자 식별자, 표시 이름, 이메일 주소, 프로필 사진 주소와 로그인 제공자 정보가 인증 계정에 연결될 수 있습니다. MwoLab은 로그인 버튼이나 공개 핏팅에 Google 표시 이름을 표시하지 않습니다.
  • 공개 핏팅: 사용자가 올린 MWO 로드아웃 코드, 좋아요 수, 생성 시각과 데이터 형식 버전만 공개됩니다. Google 이름, 이메일 주소, 프로필 사진, 고유 사용자 식별자와 같은 실제 계정 정보는 공개 핏팅에 저장하거나 표시하지 않습니다. 무기 그룹과 스킬 선택도 공개 핏팅에 포함되지 않습니다.
  • 비공개 운영 데이터: 공개 핏팅의 소유자 식별자, 사용자별 좋아요 여부, 게시 횟수와 마지막 게시물 식별자를 Cloud Firestore에 별도로 저장합니다. 이 정보는 보안 규칙으로 일반 사용자의 목록 조회를 차단하며, 공개 게시자 정보로 사용하지 않습니다.
  • 브라우저 로컬 데이터: 이름을 붙여 저장한 핏팅과 UI 설정은 사용자의 브라우저 저장소에만 보관되며 공개 핏팅을 직접 올리지 않는 한 MwoLab의 Firebase로 전송되지 않습니다.
  • 방문 통계: 사이트 이용 현황을 파악하기 위해 Cloudflare Web Analytics를 사용합니다. MwoLab은 방문 통계를 위해 자체 쿠키를 설정하지 않습니다.

3. 처리 목적

Google 로그인 유지, 공개 핏팅 게시·조회, 비공개 소유권 확인, 계정당 한 번의 좋아요 처리, 게시 한도와 서비스 오용 방지, 오류 확인 및 사이트 이용 현황 파악을 위해 위 정보를 처리합니다. 인증 정보는 게시자의 실제 신원을 공개하는 용도로 사용하지 않습니다.

4. 외부 서비스

MwoLab은 정적 페이지 호스팅에 GitHub Pages를 사용하고, 로그인과 공개 핏팅에 Google Firebase Authentication 및 Cloud Firestore를 사용하며, 방문 통계에 Cloudflare Web Analytics를 사용합니다. 각 서비스의 처리는 해당 사업자의 방침을 따릅니다.

  • Google 개인정보처리방침
  • Firebase 개인정보 및 보안 안내
  • GitHub 개인정보취급방침
  • Cloudflare 개인정보처리방침

5. 보관과 삭제

브라우저 로컬 데이터는 사용자가 브라우저 데이터를 지울 때까지 해당 기기에 남습니다. Firebase 인증 정보와 공개 핏팅 관련 데이터는 서비스 운영에 필요한 동안 보관합니다. 계정 또는 공개 핏팅 삭제를 요청하려면 위 연락처로 문의해 주세요. 요청자의 소유권을 확인한 뒤 관련 데이터를 처리합니다.

6. 공개 범위와 선택권

Google 로그인은 공개 핏팅 게시와 좋아요에만 필요합니다. 로그인하지 않아도 핵심 멕랩과 공개 핏팅 조회를 사용할 수 있습니다. 공개 핏팅을 올리면 로드아웃 코드는 누구나 볼 수 있지만 게시자의 Google 이름, 이메일, 프로필 사진과 사용자 식별자는 공개되지 않습니다. MwoLab은 개인정보를 판매하지 않으며 맞춤 광고를 제공하지 않습니다.

7. 방침 변경

처리하는 정보나 서비스 구성이 바뀌면 이 페이지와 시행일을 갱신합니다. 중요한 변경은 사이트에서 알릴 수 있습니다.

Privacy Policy

This policy applies to the MwoLab website and its public fitting features. MwoLab does not operate a separate application server or password account system. Privacy questions and deletion requests may be sent to killkimno@gmail.com.

Information processed

  • Google sign-in: Firebase Authentication may associate your Google account identifier, display name, email address, profile photo URL, and provider information with an authentication account. MwoLab does not display the Google display name on the sign-in button or with public fittings.
  • Public fittings: Only the submitted MWO loadout code, like count, creation time, and schema version are public. Google names, email addresses, profile photos, user identifiers, weapon groups, and skill selections are not stored in or displayed with public fittings.
  • Private operational records: Firestore separately stores the owner identifier, per-user like state, publish count, and last fitting identifier. Security rules block general users from listing these records, and they are not used as public author information.
  • Local browser data: Named local fittings and UI preferences remain in browser storage unless you explicitly publish a fitting.
  • Analytics: MwoLab uses Cloudflare Web Analytics to understand site usage and does not set its own analytics cookies.

Purposes, services, and retention

Information is used for authentication, public fitting publication and viewing, private ownership checks, one like per account, publish limits, abuse prevention, troubleshooting, and aggregate usage measurement. Authentication data is not used to reveal the publisher's real identity. MwoLab uses GitHub Pages, Google Firebase Authentication and Cloud Firestore, and Cloudflare Web Analytics. Local data remains until cleared from the browser; Firebase-related data is retained while needed to operate the service. Contact the address above to request account or fitting deletion. Ownership may need to be verified before deletion.

Google sign-in is optional and is required only to publish fittings or manage likes. A published fitting does not expose the publisher's Google name, email address, profile photo, or user identifier. MwoLab does not sell personal information or provide personalized advertising. This policy and its effective date will be updated if these practices materially change.
