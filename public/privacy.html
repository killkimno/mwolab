MwoLab 개인정보처리방침

시행일: 2026년 8월 27일 · Last updated: August 27, 2026

MwoLab로 돌아가기

1. 적용 범위와 운영자

이 방침은 MwoLab 웹사이트와 공개 핏팅 기능에 적용됩니다. MwoLab은 별도의 자체 서버나 자체 비밀번호 계정 시스템을 운영하지 않습니다. 개인정보 관련 문의와 삭제 요청은 killkimno@gmail.com으로 보낼 수 있습니다.

2. 처리하는 정보

  • Google 로그인: Firebase Authentication을 통해 Google 계정의 고유 사용자 식별자, 표시 이름, 이메일 주소, 프로필 사진 주소와 로그인 제공자 정보가 인증 계정에 연결될 수 있습니다. MwoLab은 로그인 버튼이나 공개 핏팅에 Google 표시 이름을 표시하지 않습니다.
  • 공개 핏팅: 사용자가 입력한 제목, MWO 로드아웃 코드, 멕 식별자, 좋아요 수, 생성 시각, 데이터 형식 버전과 Firebase 사용자 식별자(UID)가 공개 문서에 저장됩니다. UID는 소유권 확인과 내 게시물 조회에 사용하며 화면에는 작성자 정보로 표시하지 않습니다. 새 형식에는 Google 이름, 이메일 주소, 프로필 사진, 핏팅 설명, 무기 그룹과 스킬 선택을 저장하지 않습니다. 이전 v1 공개 문서에는 당시 입력한 설명이 남아 있을 수 있지만 화면에는 표시하지 않습니다.
  • 운영 데이터: 사용자별 좋아요 여부, 계정당 공개 핏팅 100개 제한을 위한 현재 게시 수·마지막 변경 핏팅 식별자·변경 종류·시각, 삭제된 핏팅의 좋아요 정리를 위한 핏팅 식별자·소유자 UID·멕 식별자·요청 시각을 Cloud Firestore에 별도로 저장합니다. 이 정보는 보안 규칙으로 일반 사용자의 목록 조회를 차단하며 게시 수는 해당 계정만 읽을 수 있습니다.
  • 브라우저 로컬 데이터: 이름을 붙여 저장한 핏팅과 UI 설정은 사용자의 브라우저 저장소에만 보관되며 공개 핏팅을 직접 올리지 않는 한 MwoLab의 Firebase로 전송되지 않습니다.
  • 방문 통계: 사이트 이용 현황을 파악하기 위해 Cloudflare Web Analytics를 사용합니다. MwoLab은 방문 통계를 위해 자체 쿠키를 설정하지 않습니다.

3. 처리 목적

Google 로그인 유지, 공개 핏팅 게시·조회, 비공개 소유권 확인, 계정당 한 번의 좋아요 처리, 서비스 오용 방지, 오류 확인 및 사이트 이용 현황 파악을 위해 위 정보를 처리합니다. 인증 정보는 게시자의 실제 신원을 공개하는 용도로 사용하지 않습니다.

4. 외부 서비스

MwoLab은 정적 페이지 호스팅에 GitHub Pages를 사용하고, 로그인과 공개 핏팅에 Google Firebase Authentication 및 Cloud Firestore를 사용하며, 방문 통계에 Cloudflare Web Analytics를 사용합니다. 각 서비스의 처리는 해당 사업자의 방침을 따릅니다.

  • Google 개인정보처리방침
  • Firebase 개인정보 및 보안 안내
  • GitHub 개인정보취급방침
  • Cloudflare 개인정보처리방침

5. 보관과 삭제

브라우저 로컬 데이터는 사용자가 브라우저 데이터를 지울 때까지 해당 기기에 남습니다. 작성자가 공개 핏팅을 삭제하면 공개 문서는 즉시 제거되고 비공개 정리 요청이 생성되며, 관리 작업에서 해당 핏팅의 좋아요 기록과 정리 요청을 제거합니다. Firebase 인증 정보와 그 밖의 공개 핏팅 관련 데이터는 서비스 운영에 필요한 동안 보관합니다. 계정 삭제를 요청하려면 위 연락처로 문의해 주세요. 요청자의 소유권을 확인한 뒤 관련 데이터를 처리합니다.

6. 공개 범위와 선택권

Google 로그인은 공개 핏팅 게시·삭제와 좋아요에만 필요합니다. 로그인하지 않아도 핵심 멕랩과 공개 핏팅 조회·적용을 사용할 수 있습니다. 공개 핏팅을 올리면 제목, 로드아웃 코드와 소유권 확인용 Firebase UID는 문서를 읽는 사용자에게 제공될 수 있지만, 화면에는 게시자의 Google 이름, 이메일이나 프로필 사진을 표시하지 않습니다. MwoLab은 개인정보를 판매하지 않으며 맞춤 광고를 제공하지 않습니다.

7. 방침 변경

처리하는 정보나 서비스 구성이 바뀌면 이 페이지와 시행일을 갱신합니다. 중요한 변경은 사이트에서 알릴 수 있습니다.

Privacy Policy

This policy applies to the MwoLab website and its public fitting features. MwoLab does not operate a separate application server or password account system. Privacy questions and deletion requests may be sent to killkimno@gmail.com.

Information processed

  • Google sign-in: Firebase Authentication may associate your Google account identifier, display name, email address, profile photo URL, and provider information with an authentication account. MwoLab does not display the Google display name on the sign-in button or with public fittings.
  • Public fittings: The submitted title, MWO loadout code, mech identifier, like count, creation time, schema version, and Firebase user identifier (UID) are stored in a publicly readable document. The UID is used for ownership checks and the user's upload list, but is not displayed as author information. New-format fittings do not store Google names, email addresses, profile photos, fitting descriptions, weapon groups, or skill selections. Older v1 public documents may retain the description submitted under that format, but it is not displayed.
  • Operational records: Firestore separately stores per-user like state; the current upload count, last changed fitting identifier, change type, and time used to enforce the 100-public-fitting account limit; and the fitting identifier, owner UID, mech identifier, and request time needed to clean up likes after deletion. Security rules block general users from listing these records, and only the account owner may read its upload count.
  • Local browser data: Named local fittings and UI preferences remain in browser storage unless you explicitly publish a fitting.
  • Analytics: MwoLab uses Cloudflare Web Analytics to understand site usage and does not set its own analytics cookies.

Purposes, services, and retention

Information is used for authentication, public fitting publication and viewing, private ownership checks, one like per account, abuse prevention, troubleshooting, and aggregate usage measurement. Authentication data is not used to reveal the publisher's real identity. MwoLab uses GitHub Pages, Google Firebase Authentication and Cloud Firestore, and Cloudflare Web Analytics. Local data remains until cleared from the browser; Firebase-related data is retained while needed to operate the service. When an owner deletes a public fitting, the public document is removed immediately and a private cleanup request is created; an administrative maintenance pass then removes the fitting's like records and the request. Contact the address above to request account deletion. Ownership may need to be verified before deletion.

Google sign-in is optional and is required only to publish or delete fittings or manage likes. Public fittings can be viewed and applied without signing in. A published document may expose its ownership UID, but the UI does not display the publisher's Google name, email address, or profile photo. MwoLab does not sell personal information or provide personalized advertising. This policy and its effective date will be updated if these practices materially change.
